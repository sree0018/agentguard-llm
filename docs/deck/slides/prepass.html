WHAT THE PRE-PASS ADDS

decoded_candidates:
base64 → "secret=hunter2"

Then the LLM decides.

It decodes and reveals

Base64, hex, percent-encoding, HTML entities, character codes, binary, spaced-out letters. Shows invisible and look-alike characters.

It never decides

No secret patterns, no verdict. Ciphers such as ROT13 or Atbash, Morse and plain prose are left to the model.

AgentGuard · local-LLM payload guard

A small model cannot reliably decode base64 or see a zero-width character, so we added a deterministic helper, normalize.py. It decodes the encodings that can be decoded mechanically and reports invisible or look-alike Unicode characters. It is evidence only: it contains no list of secret-looking patterns and it never returns allow or block. That is what separates it from the old regex. A decoded string is still treated as untrusted data. Later in the deck we show where this helped and where it did not.
