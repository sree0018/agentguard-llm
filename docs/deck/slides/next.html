AgentGuard · local-LLM payload guard

Two tracks. On the defense side: the LLM guard should sit inside a layered design. Allowlists and secret-shaped value detection catch what a language model misses, such as secrets labelled as identifiers. Alerting and rate-limiting on repeated blocks takes away the attacker's feedback loop, which is what the adaptive attacker exploits. A richer task spec derived from the user's own prompt would give the guard more context, and a bigger or fine-tuned model might follow instructions more reliably. On the evaluation side: blind cases from teammates, a live agent loop such as AgentDojo, and an LLM-driven attacker, which needs a validity check so that a bypass really leaks the secret.
