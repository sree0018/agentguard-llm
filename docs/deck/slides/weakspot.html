This is the weakness the original report admitted. The regex only matches literal patterns, so anyone who spaces out the letters, base64-encodes the secret or writes it as character codes walks straight past it. In our adaptive test set, called ADV-2, all five original obfuscation attacks got through. The regex also ignores the task entirely: it never asks whether the content makes sense for what the user wanted. That is the gap a language model can fill, because it can judge consistency, not just match strings.
