AgentGuard · local-LLM payload guard

[Meera · 8:00-8:50] Fixed attack lists only show that those attacks fail. So we built an adaptive attacker. It sees ALLOW or BLOCK, searches 28 encoders and 8 wrappers, and has 30 tries per target, with a check that every payload really contains the secret. Result: against the regex it broke 8 of 8 targets, usually on the first try. Against our strict guard, 7 of 8, after about three tries. So the guard stops one-shot attacks well, but it does not stop a determined attacker who can probe it. In real life an injected document rarely sees the verdict, so the earlier numbers are the realistic one-shot figure, but you shouldn't rely on this guard alone.
