AgentGuard · local-LLM payload guard

The sobering result. Fixed attack lists only show that specific attacks fail. So we gave an attacker a budget of 30 guard queries per target and live ALLOW or BLOCK feedback. It searches over 28 encoders and 8 wrappers, learning which combinations get through. Every payload it builds provably contains the secret, so a bypass is a real leak, not a harmless string. Result: the regex fell on all 8 targets in a single query. The strict LLM guard fell on 7 of 8, in a median of 3 queries. The relaxed variants fell too. The winning moves were exactly the weak spots from the previous slide, plus ciphers and symbol scripts. A fair nuance: this assumes the attacker can observe the guard's verdict. A prompt injection hidden in a document usually cannot, so the one-shot numbers are the realistic figure and this is a worst case. Either way, the guard is one layer, not a wall. Sample is 8 targets, so intervals are wide.
