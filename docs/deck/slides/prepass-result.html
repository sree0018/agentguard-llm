What it fixed

Everything it can decode is now caught (3 → 0), and false alarms fell from 2 to 0.

What it did not

On encodings it cannot decode, the model got worse (3 → 10). It seems to read “nothing decoded” as reassurance.

[BACKUP, not in the 10 minutes · questions go to Sreeranj] An ablation on TEST2: the same relaxed prompt, with and without the evidence pre-pass. Where the pre-pass can decode the payload, it works: those encodings go from 3 misses to 0, and false alarms go from 2 to 0. But on encodings the pre-pass cannot decode, such as Braille, flag letters or Caesar shifts, the model let more through with the pre-pass than without it, 10 against 3. Our interpretation, which is a hypothesis and not something we proved, is that the model treats an empty evidence block as a sign that everything is fine. Net effect on this set: 16 attacks through with the pre-pass against 10 without. This is the kind of result that only shows up if you run the ablation and report it either way.
