AgentGuard · local-LLM payload guard

Recap of the original project. The agent reads untrusted content and proposes a tool call. AgentGuard sits after the agent and before the tool. Checks 1 to 3 are structural: is the tool allowed, is the target in scope, is a side effect used on a read-only task. They cannot see what is inside the message body or search query. Check 4 is the only content-aware check, which is why it is the one worth attacking. A design principle from the original report that we kept: the guard never sees the retrieved document, only the pinned task and the proposed call.
