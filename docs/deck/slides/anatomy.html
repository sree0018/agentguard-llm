AgentGuard · local-LLM payload guard

[Aditya · 0:20-1:30] AI agents read content they don't control: web pages, emails, documents. Then they use tools, like sending an email. A prompt injection hides instructions in that content to hijack the agent. AgentGuard doesn't try to stop the agent from being fooled. It checks what the agent is about to do, just before the tool runs. There are four checks. One: is this tool allowed for this task? Two: is the recipient, repository or file inside the allowed scope? Three: if the task is read-only, is it trying something with side effects? Those three are fixed rules, instant and cheap. Check four asks: is the content of this message what the task would produce? It is the only check that reads the payload, so it is the only one that can stop a malicious message sent through an allowed tool to an allowed recipient. And the guard never sees the untrusted document, so the document can't talk to it directly.
