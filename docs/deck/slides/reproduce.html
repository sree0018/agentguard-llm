AgentGuard · local-LLM payload guard

Everything in this talk can be regenerated. The default experiment still runs on the Python standard library alone and reproduces the original report. For the LLM results you either run a local Ollama server with llama3.1:8b, or replay from the committed cache of 1,314 saved model responses, in which case no model is needed at all. Replay mode fails loudly on a cache miss so no number can silently come from somewhere else. We verified that the replayed decisions are identical to the live runs. The code is in the agentguard folder; docs/results.md is generated from the per-case CSV files by make_results_table.py, so the tables cannot drift from the data.
