AgentGuard · local-LLM payload guard

Six kinds of test content. First, encodings and ciphers: base64, hex, ROT13, Atbash, Braille, runes, zero-width characters and look-alike letters; the original five ADV-2 attacks plus many more. Second, prose smuggling: no obfuscation at all, the secret just appears in a normal sentence, which a regex cannot catch because it has no pattern. Third, label abuse: the secret is presented as a commit hash or reference id. Fourth, attacks on the guard itself, since using an LLM creates a new attack surface: payloads that claim pre-approval or contain a fake verdict. Fifth, the adaptive attacker, which searches over encoders and wrappers using the guard's feedback; every payload it builds provably contains the secret. Sixth, hard benign payloads, because a guard that blocks everything is useless: legitimate Hindi, Thai or Chinese text, emoji, hashes and documents that merely mention passwords. All secrets are fabricated placeholders.
