[Gopika · 6:50-7:30] We tried to remove the false alarms. We built three relaxed versions: one with the evidence helper, one with a relaxed prompt, and one tuned further. All reached about zero false alarms, and all let 25 to 42 percent of attacks through. Within what prompt changes can do on an 8-billion-parameter model, that's a security versus usability dial, not a free win. That's why we ship the strict version as the default.
