Every variant that removed false alarms let 25–42% of attacks through on held-out data.

AgentGuard · local-LLM payload guard

We tried to get the best of both worlds: a guard that is strict on attacks and quiet on benign text. We built three variants. v1 plus the evidence pre-pass, never tuned. v2, a relaxed prompt with the pre-pass. v3, tuned further on everything we had seen. All three reached roughly zero false alarms on their held-out sets, and all three let 25 to 42 percent of attacks through. So within what prompt changes can do on an 8-billion-parameter model, this is a security versus usability curve, not a free win. Note the held-out sets differ per row because a set that shaped a prompt cannot be held out for it. v2 and v3 are not statistically comparable to v1 on the same data, so read the direction, not the exact gap.
