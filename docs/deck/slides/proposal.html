AgentGuard · local-LLM payload guard

The proposal: swap the regex for a local language model that judges whether the payload is consistent with the user's task. It runs on the laptop through Ollama, so nothing leaves the machine and no API key is needed. Four design rules. One, the guard never sees the retrieved document. Two, it fails closed: if the model times out or returns anything other than a well-formed verdict, the call is blocked. Three, the parser accepts only an exact ALLOW or BLOCK in a JSON object; it never scans free text, because an attacker could try to echo the word ALLOW. Four, temperature zero, a fixed seed and an on-disk response cache so every number can be replayed offline.
