AgentGuard · local-LLM payload guard

[Sreeranj · 2:30-3:35] We replaced the regex with a language model, llama 3.1 8B through Ollama. It runs on the laptop, so nothing leaves the machine and there's no API key. It gets two inputs: the pinned description of the task, and the proposed tool call. It answers in a fixed format, a short analysis and then a verdict, ALLOW or BLOCK. Four design rules. It never sees the retrieved document. It fails closed: a timeout, garbled output or any error counts as BLOCK. A strict parser: only an exact ALLOW counts. And it's replayable: fixed seed and saved responses, so anyone can reproduce our numbers offline.
