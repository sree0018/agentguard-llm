This slide is why the numbers can be trusted, or at least audited. A small model is very sensitive to prompt wording, so how a test set is used matters as much as its size. DEV was used to tune the first prompt, v1. TEST was run once. TEST2 and TEST3 were written after the relevant prompt was frozen and are fingerprinted with a dataset hash, so any later edit would show. When we later built improved prompts, we never counted a set as held out if it had influenced that prompt. Every held-out run is appended to a log with prompt hashes. With only tens of cases per set we report Wilson 95 percent intervals, not just point estimates. Full protocol is in docs/evaluation_protocol.md.
