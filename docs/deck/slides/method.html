[Gopika · 5:00-5:40] Anyone can show two cases working, so here's how we tested properly. We wrote four test sets. One was used to tune the prompt. The other three, TEST, TEST2 and TEST3, were written after the relevant prompt was frozen. They contain encodings and ciphers, secrets in plain sentences, secrets disguised as reference IDs, attacks aimed at the guard itself, and hard harmless text like Hindi, hashes and emoji to measure false alarms. One rule: a set that shaped a prompt is never called held out for it. Every run is logged with hashes, and every rate has a 95 percent confidence interval.
