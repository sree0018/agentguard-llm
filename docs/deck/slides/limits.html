HONEST LIMITS

What this does not show

One author

The same person wrote the guard and the tests. Teammates’ blind cases are supported but not yet included.

A simulated agent

As in the original report, the agent’s behavior is modeled, not a live LLM loop.

Small samples

139 attacks and 82 benign payloads. Read the intervals, not just the percentages.

“Unseen” is limited

It means unseen by the prompt, not by the author who wrote the attacks.

A brittle model

One extra instruction made an 8B prompt worse. We reverted it and logged it.

A modest attacker

The adaptive attacker is a structured search over 8 targets, not an LLM attacker.

AgentGuard · local-LLM payload guard

Six things the results do not prove. One: the same person wrote the guard, the attacks and the benign set, so independent test cases from teammates would strengthen everything; a loader and a template are included. Two: the agent is still simulated, as in the original report. Three: the sets are small, so the confidence intervals are wide. Four: when we say a technique was unseen we mean unseen by the prompt, not by the author. Five: an 8-billion-parameter model is brittle; in one tuning round, adding an instruction made results worse, and we reverted it and recorded it. Six: the adaptive attacker is a structured search over eight targets, not a free-form LLM attacker. Saying this plainly is part of the contribution.
