The same guard, the same frozen prompt, three different test sets written at different times. The regex lets 92, 97 and 98 percent of attacks through. The LLM guard lets 8, 12 and 12 percent through. Consistency across independent sets matters more than any single number, because it suggests the 12 percent is not an artifact of one lucky test set. The prompt v1 was never changed after TEST was run. A caveat: the same author wrote the guard and all of the test sets, so teammates' blind cases are the most valuable next step.
